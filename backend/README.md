# RecipeHub API - Backend

API REST para la plataforma colaborativa de recetas RecipeHub.

## 🚀 Tecnologías

- **Node.js** + **Express** - Framework web
- **MongoDB** + **Mongoose** - Base de datos NoSQL
- **JWT** - Autenticación
- **Docker** - Contenerización
- **Jest** - Testing
